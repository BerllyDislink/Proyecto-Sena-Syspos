# Proyecto-de-Syspos

# Configuración del proyecto

## 1. Instalar Supabase CLI

```bash
pnpm install -g supabase
```

## 2. Inicializar Supabase

```bash
npx supabase@latest init
```

## 3. Crear funciones

### Crear función `create-user`

```bash
npx supabase@latest functions create create-user
```

### Crear función `new`

```bash
npx supabase@latest functions create new
```

## 4. Iniciar sesión en Supabase

```bash
npx supabase@latest login
```

---

# Instalación de dependencias

## Instalar módulos del proyecto

```bash
pnpm install
```

## Instalar Supabase JS

```bash
pnpm install @supabase/supabase-js
```

---

# Ejecutar el proyecto

```bash
pnpm run dev
```
